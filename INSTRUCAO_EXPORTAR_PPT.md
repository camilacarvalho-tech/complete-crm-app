# Como Exportar para PowerPoint

A apresentação está disponível em HTML no arquivo: `CODE_AI_Apresentacao.html`

## Opções de Exportação:

### Opção 1 - Print to PDF (Recomendado)
1. Abra o arquivo `CODE_AI_Apresentacao.html` no navegador
2. Pressione `Ctrl + P` (Print)
3. Selecione "Microsoft Print to PDF" ou "Salvar como PDF"
4. Ajuste a orientação para "Paisagem"
5. Clique em "Salvar"

### Opção 2 - Converter para PowerPoint
1. Abra o arquivo HTML no navegador
2. Use uma ferramenta online como:
   - https://www.slidemodel.com/html-to-ppt/
   - https://www.zamzar.com/convert/html-to-ppt/
3. Faça upload do arquivo HTML
4. Baixe o arquivo PPTX gerado

### Opção 3 - Captura de tela
1. Abra cada slide no navegador
2. Use ferramenta de captura (Windows + Shift + S)
3. Salve cada slide como imagem
4. Insira as imagens no PowerPoint

## Navegação na Apresentação HTML:

- **Seta Direita** ou **Espaço**: Próximo slide
- **Seta Esquerda**: Slide anterior
- **Botões**: Use os controles na parte inferior da tela
